# 线性代数直觉：换个角度重新讲一遍

> 一句话总结：所有 AI 模型做的事情，本质上就是"把一堆点在空间里搬来搬去"。线性代数就是描述这种搬运的语言。

这份笔记不是原文的翻译，而是用另一套讲法，把 `01-linear-algebra-intuition/docs/en.md` 里的核心数学概念重新讲一遍，去掉了所有代码，只保留数学直觉、公式和几何图像。

---

## 1. 向量：先别管"箭头"，把它当成一个"地址"

大多数教材告诉你"向量是一个箭头"。这个说法没错，但对理解 AI 没什么帮助。更有用的理解方式是：**向量是空间里一个点的地址（坐标），维度就是地址需要多少个数字来描述。**

比如二维向量 (4, 3)：从原点出发，横着走 4 步、竖着走 3 步，你就到了空间里唯一确定的那个点。它的长度（模）是

```
|v| = sqrt(4² + 3²) = sqrt(25) = 5
```

这是一个 3-4-5 直角三角形——勾股定理换了个说法而已。向量的模，本质上就是"这个点离原点有多远"。

**为什么 AI 里到处都是向量？** 因为神经网络需要把一切都变成"地址"才能计算：

- 一个词 → 一个 768 维（或更高）的地址，这个地址就是它在"意思空间"里的位置
- 一张图片 → 一个几百万维的地址，每一维是一个像素的亮度
- 一个用户的偏好 → 一个几十到几百维的地址

关键的直觉转变是：**意思相近的词，它们的地址在空间里也相邻**。"国王"和"女王"的向量离得很近，"国王"和"香蕉"的向量离得很远。这不是巧合，而是训练过程强行把语义关系"塞"进了几何距离里。这也是为什么"向量数据库"检索的本质就是"找地址相近的点"。

## 2. 矩阵：不是表格，是一台"空间搬运机"

把矩阵当成一张数字表格，是最没用的理解方式。更准确的理解是：**矩阵是一个函数，输入一个向量，输出另一个向量**——它把空间里的每一个点，按照统一的规则搬到另一个位置。

这个"规则"可以是：

- 旋转（把所有点绕原点转个角度）
- 缩放（把所有点沿某个方向拉伸或压缩）
- 投影（把高维的点压扁到低维，比如把 3D 影子打到 2D 墙上）
- 或者是以上几种的任意组合

关键点在于：**矩阵对空间的操作是"一次性、整体性"的**——它不是挑着改某几个点，而是用同一套线性规则，同时搬动空间里所有的点。这就是"线性"两个字的含义：直线还是直线，原点还是原点，平行还是平行，只是角度、长度、位置变了。

**神经网络就是一串"搬运机"叠在一起**：输入向量先被第一层矩阵搬到一个新空间，再经过一个非线性"拐弯"（激活函数），再被第二层矩阵搬一次……层数越多，能够表示的搬运方式就越复杂、越扭曲。你可以把一个深度网络想象成，把一团揉皱的纸（数据）反复拉伸、折叠、翻转，直到不同类别的点被分到空间里不同的区域。

在 AI 里，矩阵不只是"运算工具"，矩阵本身**就是模型**：权重矩阵、注意力打分矩阵、词嵌入矩阵——它们都是被训练出来的"搬运规则"。

## 3. 点积：用一个数字回答"这两个方向像不像"

点积的公式很简单：

```
a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ
```

但公式本身没有告诉你它"为什么有用"。真正有用的是它的几何身份：

```
a · b = |a| · |b| · cos(θ)
```

其中 θ 是两个向量之间的夹角。把这个式子倒过来看：**点积其实是在用一个数字，量化"两个方向对齐的程度"**。

- 夹角为 0°（方向完全相同）：cos(θ) = 1，点积达到最大，等于两个模长的乘积
- 夹角为 90°（互相垂直）：cos(θ) = 0，点积等于 0，两者"互不相关"
- 夹角为 180°（方向完全相反）：cos(θ) = -1，点积为负

如果你把两个向量的模长都归一化成 1（也就是只保留方向、不管长度），点积就直接等于 cos(θ)——这正是"余弦相似度"的来历。

**这就是整个现代检索技术的数学基础。** 搜索引擎、推荐系统、RAG（检索增强生成）做的所有事情，归根结底都是同一个操作：把查询变成一个向量，把候选内容也变成向量，然后用点积去找"方向最接近"的那些向量。Transformer 里的注意力机制也是同一个操作——每个词的 Query 向量和其他词的 Key 向量做点积，点积越大，说明这两个词"越应该互相关注"。

## 4. 线性无关：你以为你有 N 个自由度，其实可能没有

给你一组向量，如果其中任何一个都不能由其余向量"拼凑"（线性组合）出来，这组向量就叫**线性无关**。反过来，只要有一个能被其他几个拼出来，这组向量就是**线性相关**的。

这个概念的关键不在于定义本身，而在于它回答了一个更实际的问题：**这几个向量到底张开了几维空间？**

举个例子：

```
v1 = (1, 0, 0)
v2 = (0, 1, 0)
v3 = (2, 1, 0)      注意：v3 = 2·v1 + v2
```

v1 和 v2 无关，它们撑起了一整个 xy 平面。但 v3 只是 v1 和 v2 拼出来的一个"影子"，它没有带来任何新方向。所以哪怕你有三个向量，它们能够到达的地方，依然只是同一个二维平面——你永远拼不出 (0, 0, 1) 这个点。**表面上是三个自由度，实际上只有两个。**

**为什么这对 AI 是致命的：** 如果你的数据集里有一列特征，恰好是另外几列特征的线性组合（比如"总价 = 单价 × 数量"，你把这三列都当作特征喂进模型），这一列并没有给模型带来任何新信息。更糟的是，它会让求解权重的方程组变成"病态"甚至"无解"——因为数学上存在无穷多组权重都能同样"完美"地拟合训练数据，模型不知道该选哪一组，于是权重变得极不稳定，输入稍微抖动一下，输出就剧烈波动。这就是"多重共线性"问题的本质：不是数据错了，是自由度被高估了。

## 5. 基与秩：换一把"尺子"衡量信息量

**基（basis）** 是一组"最省"的线性无关向量，多一个都嫌多，少一个就撑不满整个空间。基向量的个数，就定义了这个空间的维度。

有意思的是：基不是唯一的。三维空间的"标准基"是 (1,0,0)、(0,1,0)、(0,0,1)，但任何三个互相无关的向量都可以当作一套新的基——这本质上是换了一套坐标系去描述同样的空间。选哪套基不影响空间本身，只影响你描述起来方不方便（PCA 做的事情，正是去找一套"更方便"的基）。

**秩（rank）** 则是把"线性无关"这个概念，直接套用在矩阵上：一个矩阵的秩，就是它的列（或行）里，最多能挑出几个线性无关的向量。

| 情况 | 秩 | 对模型意味着什么 |
|---|---|---|
| 满秩（秩 = 行数和列数中较小者） | 达到理论最大值 | 方程组有唯一的最小二乘解，模型"条件良好" |
| 秩亏（秩 < 理论最大值） | 低于最大值 | 特征之间存在冗余，权重解不唯一，需要正则化来"选"出一组解 |
| 秩为 1 | 1 | 矩阵里每一列都只是同一个方向的缩放，所有数据实际上躺在一条直线上 |
| 接近秩亏（存在很小的奇异值） | 数值上偏低 | 矩阵"病态"，极小的输入噪声会被放大成极大的输出误差 |

**秩是理解 LoRA 的钥匙**（下文详述）：LoRA 假设"权重的更新量"这个矩阵其实秩很低，也就是说，虽然它表面上是一个巨大的矩阵，但真正携带的信息量，其实只需要一个小得多的空间就能装下。

## 6. 投影：把"用不上的方向"直接扔掉

把向量 **a** 投影到向量 **b** 上，问的是：**a 里有多少"分量"是沿着 b 这个方向的？**

```
proj_b(a) = ( (a · b) / (b · b) ) · b
```

拆开来看这个公式在做什么：`a · b` 衡量了 a 沿 b 方向的"含量"，除以 `b · b`（也就是 |b|²）是在做归一化，最后乘回 b 是把这个"含量"变回一个真正沿 b 方向的向量。

投影之后剩下的部分，`a - proj_b(a)`，叫作残差，它一定和 b **垂直**。这一点看似是个几何巧合，实际上是整个最小二乘法的根基：**残差与投影方向垂直，等价于"你已经把能用 b 解释的部分全部榨干了，剩下的和 b 再无瓜葛"。**

举个具体的例子：a = (3, 4)，投影到 b = (1, 0) 这个方向（也就是 x 轴）：

```
proj_b(a) = (3×1 + 4×0) / (1×1 + 0×0) × (1, 0) = 3 × (1, 0) = (3, 0)
```

y 分量被直接丢掉了。这其实就是"降维"最朴素的样子：**你留下你关心的方向，把剩下的方向扔进垃圾桶。**

在 AI 里，投影几乎无处不在：

- 线性回归的解，本质上就是把观测值投影到"所有特征能张成的那个空间（列空间）"里,残差最小的地方就是最优解
- PCA 就是在寻找"投影后数据分散得最开"的那几个方向，然后把数据往那几个方向上投影，扔掉方差小的方向
- Transformer 的注意力机制里，Query 和 Key 做点积，本质上也是在计算"一个向量在另一个方向上的投影量有多大"

## 7. Gram-Schmidt 与 QR 分解：把一堆歪七扭八的向量"扶正"

给你一组线性无关但互相不垂直、长度也不统一的向量，Gram-Schmidt 过程要做的事情是：**逐个把它们改造成互相垂直、且长度都为 1 的一组新向量（正交单位基）**，同时保证它们张成的空间完全不变。

思路其实就是不断重复"投影再减去"这个动作：

1. 第一个向量：直接归一化，得到 u₁
2. 第二个向量：先算出它在 u₁ 方向上的投影分量，减掉这部分（这样剩下的部分就与 u₁ 垂直了），再归一化，得到 u₂
3. 第三个向量：分别减掉它在 u₁、u₂ 方向上的投影分量（保证同时与两者都垂直），再归一化，得到 u₃
4. 依此类推，每处理一个新向量，就把它在"已经处理好的所有方向"上的分量清空

用记号写出来就是：

```
u1 = v1 / |v1|

w2 = v2 - (v2·u1) u1
u2 = w2 / |w2|

w3 = v3 - (v3·u1) u1 - (v3·u2) u2
u3 = w3 / |w3|
```

每一步都在做同一件事——第 6 节讲的投影和减法——只是重复应用在越来越多的方向上。

**这正是 QR 分解的底层逻辑**：把一个矩阵 A 拆成 A = QR，其中 Q 是 Gram-Schmidt 处理后得到的正交单位基（列向量互相垂直、长度为 1），R 是记录"每一步投影系数"的上三角矩阵。QR 分解之所以重要，是因为正交矩阵在数值计算上极其"温顺"（不会放大误差），所以它被用在：

- 求解线性方程组（比高斯消元法在数值上更稳定）
- 计算矩阵的特征值（QR 算法反复做 QR 分解再重组，最终收敛出特征值）
- 最小二乘回归（工业界求解回归系数的标准数值方法，而不是直接套用正规方程）

## 8. 把这些概念串起来看 AI

这几个概念不是孤立的知识点，它们其实是同一件事的不同侧面——**"如何在高维空间里，找到、保留、丢弃信息"**：

- **点积**回答"两个方向像不像"——检索、注意力打分的核心
- **矩阵乘法**回答"如何把一个空间整体搬到另一个空间"——每一层神经网络在做的事
- **线性无关/秩**回答"这组向量/这份数据真正有几个自由度"——判断特征冗余、方程组是否可解
- **投影**回答"沿着我关心的方向，信息有多少，其余的能不能扔"——回归、PCA 的数学核心
- **Gram-Schmidt/QR**回答"如何把一堆歪的方向系统性地扶正，让后续计算既快又稳"——数值算法的地基

**LoRA 是这套直觉最漂亮的实战案例。** 微调一个大语言模型时，如果直接更新一个 4096×4096 的权重矩阵，意味着要调整约 1600 万个参数。LoRA 的假设是：这次更新真正需要的信息量，其实只需要一个"秩为 16"的矩阵就能装下——于是它把更新量拆成两个小矩阵，一个 4096×16，一个 16×4096，加起来只有约 13 万个参数，却假设能覆盖住"权重更新"这件事真正需要的自由度。这不是工程上的取巧，而是秩这个数学概念在真实地发挥作用：**用一个低维子空间去近似一个理论上高维、但实际信息量并不高的变化。**
