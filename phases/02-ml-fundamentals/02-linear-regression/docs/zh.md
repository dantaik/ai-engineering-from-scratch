# 线性回归：亲手推一遍 dMSE/dw 和 dMSE/db，看懂 R² 在比什么

> 一句话总结：训练就是"猜参数 → 算多离谱（MSE）→ 问微积分该往哪调（梯度）→ 反方向挪一小步"的循环。dMSE/dw 和 dMSE/db 就是"往哪调、调多狠"的答案；R² 则回答训练完之后的灵魂拷问——"你比永远瞎猜平均值，到底强多少？"

这份笔记不是 `02-linear-regression/docs/en.md` 的翻译。原文直接给出了两个梯度公式和 R² 的定义，但没有展开推导和解读。这里把这三个公式当主角：梯度公式一步一步亲手推出来，讲清每一项是从哪掉下来的、直觉上在说什么；R² 讲清它背后那场"和笨基线的比赛"。上一课的中文笔记已经讲过 MSE 为什么用平方（正负不抵消、大错重罚、光滑可导），这里不再重复，直接从求导开始。

---

## 1. 舞台：两个旋钮，一只碗

线性回归的模型只有一行：

```text
ŷ = w·x + b
```

w 是斜率，b 是截距。整个模型就这两个旋钮。给定训练数据，损失函数是均方误差：

```text
MSE(w, b) = (1/n) · Σ (ŷᵢ - yᵢ)²      其中 ŷᵢ = w·xᵢ + b
```

关键的视角转换是：**把 MSE 看成 w 和 b 的函数，而不是 x 的函数。**数据 (xᵢ, yᵢ) 在训练时是固定不动的，会动的只有 w 和 b。你每转动一次旋钮，就得到一条新的直线，也就得到一个新的 MSE 值。

把所有可能的 (w, b) 组合和对应的 MSE 画出来，是一个三维曲面。因为 MSE 对 w、对 b 都是二次函数，这个曲面是一只**碗**（凸抛物面）：只有一个最低点，没有假坑。训练的目标就是找到碗底。

问题来了：你被蒙着眼放在碗壁上的某个位置（随机初始化的 w 和 b），怎么知道往哪边走是下坡？这正是导数要回答的问题。

---

## 2. 工具箱：只需要两件微积分工具

推导只用到两样东西，先用二十秒对齐：

1. **偏导数**：MSE 有两个自变量（w 和 b），"偏导"就是**只转一个旋钮、按住另一个不动**，看损失变化多快。dMSE/dw 问的是"w 挪一丁点，MSE 变化几倍"；dMSE/db 同理。（严格的写法是 ∂MSE/∂w，读作"偏导"；本文沿用原文的记号写成 dMSE/dw，意思一样。）
2. **链式法则**：复合函数求导，等于**外层导数乘以内层导数**，像剥洋葱一样从外往里一层层剥。两条现成的结论马上要用：u² 对 u 的导数是 2u；常数的导数是 0。

就这些。下面开始推。

---

## 3. 推导 dMSE/dw：像剥洋葱一样用链式法则

MSE 是一堆样本损失的平均，而"和的导数 = 导数的和"，所以只要推明白**一个样本**的损失，剩下的就是求和取平均。单个样本的损失是：

```text
Lᵢ = (ŷᵢ - yᵢ)²      其中 ŷᵢ = w·xᵢ + b
```

这是一个两层的洋葱：外层是"某个东西的平方"，内层是"那个东西"本身。

**第一步，剥外层。**把括号里的整体记作 u = ŷᵢ - yᵢ，那么 Lᵢ = u²：

```text
dLᵢ/du = 2u = 2(ŷᵢ - yᵢ)
```

**第二步，剥内层。**u 对 w 求导。展开 u = w·xᵢ + b - yᵢ，注意此刻 xᵢ、yᵢ、b 全是"别人家的常数"——求 w 的偏导时它们都不动：

```text
du/dw = d(w·xᵢ + b - yᵢ)/dw = xᵢ + 0 - 0 = xᵢ
```

**第三步，链式相乘。**

```text
dLᵢ/dw = 2(ŷᵢ - yᵢ) · xᵢ
```

对 n 个样本求和、取平均，就得到原文里那条公式：

```text
dMSE/dw = (2/n) · Σ (ŷᵢ - yᵢ) · xᵢ
```

推完了。现在逐项验明正身，每一项都有来头：

| 公式里的成分 | 从哪来 | 直觉上在说什么 |
|---|---|---|
| (ŷᵢ - yᵢ) | 外层平方求导 | 第 i 个点的误差：预测偏高为正，偏低为负 |
| × xᵢ | 内层 w·xᵢ 求导 | 这个点对 w 的"发言权"：ŷᵢ 对 w 的敏感度恰好是 xᵢ |
| 2 | 平方的指数掉下来 | 一个常数而已，实践中被学习率吸收 |
| 1/n | 对样本取平均 | 让梯度大小不随数据集规模乱变 |

最值得咀嚼的是那个 **× xᵢ**：为什么误差要乘上输入？想象 w 是一块跷跷板的倾角，x 是每个点离支点的距离。倾角转动一格，**坐得远的点（x 大）上下移动的幅度大，坐得近的点几乎不动**。所以 x 大的样本上出现的误差，对"该怎么调倾角"有更大的发言权——它们的误差被 xᵢ 加权放大。这不是拍脑袋的设计，是链式法则自动算出来的公道。

顺带解决一个新手常见困惑：有的教材把 MSE 写成 1/(2n) 而不是 1/n，就是为了让求导时掉下来的 2 正好被约掉、公式更干净。系数差一倍无关紧要——它会被学习率吸收，两种写法训练出来的模型没有区别。**不同的书公式长得不一样，不是谁错了，是常数放哪的口味问题。**

---

## 4. 推导 dMSE/db：同一把刀，切得更快

对 b 求导，洋葱的外层一模一样，只有内层不同。u = w·xᵢ + b - yᵢ 对 b 求导时，轮到 w·xᵢ 和 yᵢ 当常数：

```text
du/db = d(w·xᵢ + b - yᵢ)/db = 0 + 1 - 0 = 1
```

链式相乘、求和取平均：

```text
dLᵢ/db = 2(ŷᵢ - yᵢ) · 1
dMSE/db = (2/n) · Σ (ŷᵢ - yᵢ)
```

对比一下两条公式，你会发现它们共享同一个骨架：

```text
梯度 = (2/n) · Σ 误差ᵢ × ( 该参数对第 i 个预测的影响力 )

对 w：影响力 = xᵢ     （跷跷板倾角：远处的点动得多）
对 b：影响力 = 1      （整块板垫高：所有点同步平移一格）
```

b 的梯度里没人被加权，因为截距抬高 1，**每个点的预测都恰好抬高 1**，人人平等，所以 dMSE/db 就是"平均误差 × 2"。

用它检验一下方向对不对：如果模型整体预测偏高（误差之和为正），dMSE/db 为正，更新规则 b = b − lr × 正数会把 b 调小，整条线往下压——完全符合常识。微积分推出来的结论，和你盯着散点图的第一反应是同一个，这正是它该有的样子。

---

## 5. 拿到梯度之后：为什么更新规则里是减号

导数的定义决定了它指向**上坡**方向——dMSE/dw > 0 意味着"w 增大，损失跟着增大"。我们要下坡，所以反着走：

```text
w = w - learning_rate × dMSE/dw
b = b - learning_rate × dMSE/db
```

那个减号不是约定俗成，是"梯度指上坡、我们要下坡"的直接后果。学习率（learning rate）控制步幅：太大，一步跨过碗底、在两侧碗壁上越弹越高（发散）；太小，一辈子在碗壁上磨蹭。常见起手值是 0.01、0.001。

整个训练循环收拢成一张图：

```mermaid
flowchart LR
    A["初始化 w, b"] --> B["前向：ŷ = wx + b"]
    B --> C["算损失 MSE"]
    C --> D["算梯度 dMSE/dw、dMSE/db"]
    D --> E["逆着梯度挪一步"]
    E -->|"损失还在降"| B
    E -->|"降不动了"| F["收敛：碗底附近"]
```

## 6. 亲手算一轮：看梯度把线"掰"向数据

空谈直觉不如算一遍。三个数据点：(1, 2)、(2, 3)、(3, 5)。从最无知的状态出发：w = 0，b = 0（一条趴在 x 轴上的水平线），学习率取 0.05。

**第一步：前向传播。**w = 0、b = 0，三个点的预测全是 0。

```text
误差 (ŷᵢ - yᵢ)：  0-2 = -2,   0-3 = -3,   0-5 = -5
MSE = (4 + 9 + 25) / 3 ≈ 12.67
```

**第二步：算两个梯度。**

```text
dMSE/dw = (2/3) × [(-2)(1) + (-3)(2) + (-5)(3)] = (2/3) × (-23) ≈ -15.33
dMSE/db = (2/3) × [(-2) + (-3) + (-5)]          = (2/3) × (-10) ≈ -6.67
```

两个梯度都是负数。读出它的含义：**"往正方向调 w 和 b，损失会下降"**——预测全线偏低，微积分在喊"抬起来"。而且 dMSE/dw 的绝对值比 dMSE/db 大一倍多，因为误差最惨的点 (3, 5) 坐在跷跷板远端（x = 3），它把"调斜率"的呼声放大了三倍。

**第三步：逆着梯度挪一步。**

```text
w = 0 - 0.05 × (-15.33) ≈ 0.77
b = 0 - 0.05 × (-6.67)  ≈ 0.33
```

**第四步：验收。**新直线 ŷ = 0.77x + 0.33 的预测是 1.10、1.87、2.63：

```text
新误差：-0.90, -1.13, -2.37
新 MSE = (0.81 + 1.28 + 5.61) / 3 ≈ 2.57
```

一步之内，损失从 12.67 砍到 2.57，掉了将近八成。之后的每一轮都在重复这四步，只是步子越来越小（越接近碗底，坡度越缓，梯度自动变小），最终收敛到这组数据的最优解 ŷ = 1.5x + 0.33 附近。这三个数字——记住这条最优线，下一节接着用。

---

## 7. R²：你比"永远猜平均值"强多少

训练完了，MSE = 2.57，这到底算好还是烂？**MSE 自己回答不了这个问题**，它有两个先天缺陷：

1. **单位很怪**：预测房价（万元），MSE 的单位是"万元的平方"，没有人对"平方万元"有直觉。
2. **尺度依赖**：同一个模型，把 y 的单位从"元"换成"万元"，MSE 缩小一亿倍——数字变了，模型没变。拿不同问题的 MSE 互相比较毫无意义。

R² 的解法是给 MSE 找一个**参照物**：一个谁都能做到的笨基线——**不看任何特征，永远预测 y 的平均值 ȳ**。然后问一个公道的问题：笨基线犯的错里，你的模型消灭掉了百分之多少？

```text
R² = 1 - SS_res / SS_tot

SS_res = Σ (yᵢ - ŷᵢ)²      残差平方和：你的模型没消灭掉的误差
SS_tot = Σ (yᵢ - ȳ)²       总平方和：笨基线的误差，也就是 y 自身的总波动
```

SS_res / SS_tot 是"你还剩下的错误占笨基线的比例"，1 减去它，就是"你消灭掉的比例"。这也解释了那句到处能看到的黑话——"模型解释了 y 的多少方差"：SS_tot 是 y 的全部波动，SS_res 是模型解释不了、剩下的波动，R² 就是**被解释掉的波动占比**。

用第 6 节的数据算一遍。三个点 (1, 2)、(2, 3)、(3, 5)，收敛后的直线 ŷ = 1.5x + 0.33：

```text
ȳ = (2 + 3 + 5) / 3 ≈ 3.33
SS_tot = (2-3.33)² + (3-3.33)² + (5-3.33)² ≈ 1.78 + 0.11 + 2.78 ≈ 4.67

预测：1.83, 3.33, 4.83
SS_res = (2-1.83)² + (3-3.33)² + (5-4.83)² ≈ 0.03 + 0.11 + 0.03 ≈ 0.17

R² = 1 - 0.17 / 4.67 ≈ 0.96
```

读法：**笨基线 96% 的错误被这条直线消灭了。**这个 0.96 不带单位、不随 y 的量纲变化（分子分母单位相同，相除时消掉了）——不管你预测的是房价还是气温，R² 都在同一把尺子上。

刻度表，注意最后一行：

| R² | 怎么读 |
|---|---|
| 1.0 | SS_res = 0，每个点都分毫不差 |
| 0.9 | 笨基线九成的错误被消灭了 |
| 0.0 | 和笨基线打平——特征白学了，模型等于没有 |
| **< 0** | **比永远猜平均值还差** |

很多人以为 R² 的取值范围是 0 到 1——不对，**上限是 1，下限是负无穷**。只要 SS_res 比 SS_tot 还大，R² 就是负的。训练集上的线性回归不会出现这种情况（最差也能退化成猜平均值），但在**测试集**上完全可能：模型把训练数据的噪声背了下来，到新数据上错得比瞎猜还离谱。**测试集上的负 R² 是过拟合最响亮的警报。**

最后三条使用须知，让你不被这个数字骗到：

- **该看的是测试集上的 R²。**训练集 R² 高说明拟合得紧，不说明泛化得好——一条硬背训练点的十次多项式，训练 R² 能逼近 1，测试 R² 却可能直接负掉。
- **往模型里加特征，训练 R² 永远不会下降**——哪怕加的是纯噪声列，最差也就是给它一个零权重。所以比较特征数不同的模型时，人们用"调整 R²"（Adjusted R²），它对特征个数收罚款。
- **R² 高不等于因果，也不保证"关系真的是直线"。**四组分布完全不同的数据可以算出几乎相同的 R²（统计学里著名的 Anscombe 四重奏）。数字看完，散点图和残差图还是得画。

顺手记一个漂亮的恒等式：把 SS_res 和 SS_tot 同时除以 n，分子变成 MSE，分母变成 y 的方差，于是 **R² = 1 − MSE / Var(y)**。R² 不是一个新指标，它就是"用 y 自身的方差给 MSE 归一化，再翻个面"。

---

## 8. 收尾：一个骨架，两条公式，一张成绩单

- **dMSE/dw = (2/n)·Σ(ŷᵢ−yᵢ)·xᵢ**：误差加权和，权重是 xᵢ——斜率是跷跷板，远处的点发言权大。链式法则两步剥出来：外层平方给出 2(ŷᵢ−yᵢ)，内层线性给出 xᵢ。
- **dMSE/db = (2/n)·Σ(ŷᵢ−yᵢ)**：平均误差——截距是整体平移，人人平等，没人加权。
- 两条公式共用一个骨架：**梯度 = 误差 × 该参数对预测的影响力，再求平均**。这个骨架不是线性回归的专利：第 3 阶段的反向传播课里你会看到，训练任何神经网络，本质上就是用链式法则把这个"误差 × 影响力"沿着一层层网络往回传。今天在两层洋葱上练的手艺，将来直接用在一百层的洋葱上。
- **R² = 1 − SS_res/SS_tot**：把"你剩下的错误"和"永远猜平均值的错误"打个比，回答 MSE 回答不了的问题——这个成绩到底算好算坏。满分 1，及格线 0，下不封底；测试集上见了负数，先查过拟合。
