Scaling Laws：把「大力出奇迹」写成公式

Kaplan 2020 · Hoffmann（Chinchilla）2022 · L(N,D) = E + A/N^α + B/D^β · C ≈ 6ND

深度学习最重要的经验发现之一：把参数 N、数据 D、算力 C 各放大十倍、千倍、百万倍，交叉熵损失沿一条 log-log 直线平滑下滑——是幂律，没有突变，也没有观测到饱和。由此背出五条可操作的「真理」：规模压倒形状、损失可预测、算力要分账、最优随目标改变、底线到不了。它不承诺智能免费，只公布价格表：可消减的那部分损失每减半，算力约要 ×90。

1 · 现象：一条跨过七个数量级的直线

2020 年 Kaplan 等人把上百个不同大小的 Transformer 语言模型的最终损失画到双对数纸上，得到三条几乎笔直的线——分别对着参数 N、数据 D、算力 C（每次只放大一个、其余不设瓶颈）：

L(N) ∝ N^(−0.076)      参数扩 10 倍 → 可消减损失 ×10^(−0.076) ≈ ×0.84
L(D) ∝ D^(−0.095)      数据扩 10 倍 → ×0.80
L(C) ∝ C^(−0.050)      算力扩 10 倍 → ×0.89
（Kaplan 2020 的拟合指数；具体数值依赖分词器与数据集，形状不依赖）

「幂律」有两个读法。读法一：log-log 直线——横竖轴都取对数后是直线，于是跨过七个数量级不弯、不断、不跳。读法二：无特征尺度——曲线上不存在一个「开窍点」；在 10⁷ 参数处 ×10 和在 10¹¹ 参数处 ×10，按比例算回报率相同。所谓「真理」，首先就是这条曲线的平滑本身：模型变强不靠灵感和运气，是规模的连续函数。

2 · 真理一：规模压倒形状——N、D、C 是指数，架构是常数

同一批实验里 Kaplan 还测了「形状」：固定参数量 N，把网络排成深而窄、浅而宽，改注意力头数、改 FFN 宽窄比——在很宽的范围内，损失只差百分之几。而 N、D、C 每动一个数量级，损失动的是档位。写成一句话：

规模压倒形状

在「模型是不是够大、喂没喂饱、算力给没给够」面前，「网络长什么样」是二阶小量。架构的好坏体现为换一条更低的线（改常数项 A、B），规模的作用是沿着线往前走（走指数项）。前提是架构得先「够格上线」——同实验里 LSTM 加深加宽会提前饱和，根本画不出这条持续下行的直线；Transformer 能。

这是 Sutton「苦涩的教训」（2019）的定量版：能吃下算力的通用方法，最终赢过精巧的人工设计。它直接改变了 2020 年以后的研发分工——调结构的收益封顶在几个百分点，于是主力资源转向抬 N、D、C；结构创新要证明自己，标准也变成了「你把线平移了多少」（§8 的「等效算力」）。

3 · 真理二：损失可预测——训练从赌博变成工程

直线最值钱的性质是可外推。在小尺度训练一排模型，拟合出常数和指数，就能填出千倍、万倍算力处的损失。GPT-4 技术报告给过实证：用不超过最终算力 1/10000 的小实验，提前算准了最终训练损失。九位数美元一次的训练敢按下开始键，全部底气就是这条线：先花 1% 的算力买地图，再花 99% 的算力走路。

Kaplan 还有一条常被漏掉的附带发现：大模型更省样本——到达同一损失，大模型需要的 token 反而更少。「先把模型做大」在当时不是虚荣，是拟合曲线给出的理性策略。至于「大」了之后算力该怎么在 N 和 D 之间分——他们给的答案是错的，这正是下一条真理。

4 · 真理三：算力要分账——C ≈ 6ND，谷底在 N 与 D 齐头并进处

标准 Transformer 里，每个参数每个 token 前向约 2 FLOPs、反向约 4 FLOPs，所以总算力 C ≈ 6·N·D。预算 C 定死之后，N 和 D 就在一条双曲线上此消彼长：模型 ×10，数据就得 ÷10。往哪边分？

Kaplan 的答案是「优先加 N」，GPT-3 照办：175B 参数只喂 300B token，1.7 token/参数。2022 年 Hoffmann 等人重做实验（关键修正：学习率衰减日程要按实际 token 预算配齐，Kaplan 没配，系统性低估了数据的价值），结论翻案：N 与 D 应当等比放大，标题数字是 20 token/参数。验证也直接——同一档算力预算（≈6×10²³ FLOPs）下，Chinchilla 用 70B×1.4T 的分法全面胜过 280B×300B 的 Gopher，也胜过 GPT-3，推理成本还便宜 2.5 倍。GPT-3 不是不够大，是饿着。

Chinchilla 顺手给出了损失的完整形状，两面「墙」相加，再加一个到不了的底：

L(N, D) =   E   +   A/N^α   +   B/D^β
          ──底──   ──参数墙──   ──数据墙──
E = 1.69   A = 406.4   B = 410.7   α = 0.34   β = 0.28   （本课 code/main.py 所用拟合）

固定 C 沿双曲线滑动，两面墙一边降一边升，损失走出 U 形谷；谷底就是最优分账：

用同一组常数在各档预算下求谷底（code/main.py 的输出）：

算力 C（FLOPs）N*D*D*/N*谷底 L
10¹⁸78.4M2.1B273.535
10²⁰659M25.3B382.600
10²²5.1B330B652.139
10²⁴42.5B3.9T921.911

注脚：表里 D*/N* 从 27 涨到 120，不是恒等于 20——用这组公式常数（论文的方法三拟合，α=0.34、β=0.28 不完全对称）算出的最优配比会随 C 缓慢升高；「20 token/参数」来自论文另外两种实验拟合，对应其研究的算力段（10²²~10²³）。真理在「N 与 D 要一起长」，不在 20 这个具体数字。

5 · 真理四：「最优」只对训练账本最优——过训练时代

Chinchilla 的「最优」有严格的限定语：每一训练 FLOP 换到的损失最低。但训练成本付一次，推理成本付到天荒地老。给要服务海量请求的模型算总账，账本就变了：参数 N 直接决定每次推理的 FLOPs，于是值得把模型压小、把训练拉长——故意偏离谷底，用多付的训练算力换永久的推理折扣。

用 §4 的公式给这笔交易标价（main.py，预算 C = 10²⁴ 不变）：谷底分法是 42.5B×3.9T、L=1.911；改成 4.2B×39T（N ÷10、D ×10），L=1.971。损失只贵 +0.06，推理从此便宜 10 倍。2026 年的主流模型全在做这道题：

模型NDD/N公式预测 L
GPT-3（2020）175B300B1.72.002
Chinchilla（2022）70B1.4T201.937

读这张表：GPT-3 在 D/N=1.7 处挨饿；Chinchilla 站在 20 的谷底；Llama 3 8B 冲到 1875——超过谷底配比约 90 倍，损失只比同数据的 70B 版本高 0.09，却能塞进一张消费级显卡。Sardana & Frankle（2024）把这套「把推理写进目标函数」的账算成了正式公式：推理量越大，合理配比越往 100~500 token/参数走。

这条真理的正确读法

定律没有被推翻，被换掉的是目标函数。scaling law 给出的是换算率（多付多少训练 FLOPs ⇌ 省多少损失/推理 FLOPs），至于优化什么——训练成本、服务成本、还是显存上限——由你的业务定。「最优」永远是「对某个账本的最优」。

6 · 真理五：有一条到不了的底——E，数据自身的熵

公式里的 E = 1.69 nats/token（≈2.4 bit/词元）是 N→∞、D→∞ 都消不掉的不可约损失。剩下的这部分不是模型笨，是语言本身：给定上文，下一个词天然存在真随机（「我中午吃了___」），以及文本里根本不含答案的信息。损失到不了 0，也不该指望——能完美预测下一个词，等于宣称世界是一篇确定性的文章。

底线的存在把「收益递减」变成了精确陈述。在最优前沿上，可消减损失 L−E ∝ C^(−0.15)（本课常数）：

算力 ×10 → 可消减损失剩 70%；想把它减半，要付约 91 倍算力；图 1 里同样宽的一步，左端买到 −0.55、右端只剩 −0.07。越接近底线，每个数量级的算力买到的绝对进步越小——而算力是按数量级涨价的。

所以「继续堆算力」在 10²⁶ FLOPs 时代不再是万能答案：超过谷底配比千倍以后，log-loss 的变化已接近测量噪声。这不是 scaling 的失败，是这条幂律自己预言的形状——它同时解释了为什么 2024 年以后的重心转向 §8 的那些「搬常数」的杠杆。

7 · 真理的边界：loss 平滑，不等于能力平滑

2022 年流行过一种说法：算术、多步推理等能力会在某个规模「涌现」——曲线上毫无征兆，某一档突然会了。若为真，幂律的可预测性就废了一半：损失可测，能力不可测，预算还是没法排。

Schaeffer 等人（2023）给出泼冷水的解释：跳变多半是打分函数制造的。「五位数乘法」用全对才得分的 exact-match 打分，模型每一位数字的正确率其实在平滑上升，「整题全对」的概率自然像开关一样啪地翻转——把不连续的尺子换成连续指标（逐 token 交叉熵），同一批模型的曲线就平滑了。海市蜃楼在尺子里,不在模型里。

2026 年的工程共识：预算规划一律对着连续指标做，基准分数的跳变先怀疑打分方式。但边界依然真实：定律预测的是分数，不是体验——某个具体产品能力（写对 SQL、按格式回话）何时跨过「够用」的门槛，仍然要实测。真理管损失，不管惊喜。

8 · 定律不是宿命：常数会搬家，形状不动

2022 → 2026 年所有让训练「更划算」的进步，放进公式看做的都是同一件事：改常数，不改形状。业内把这记成「等效算力倍增器」——好数据、好优化器让每个 FLOP 顶两个用，整条线向左平移，指数与底线 E 原地不动：

杠杆动了公式的哪里等效算力
数据清洗（Phi 式）同样的 D 含更多信息 → 常数 B 变小>2×
Muon 优化器同 loss 少走一半步数 → 常数整体平移≈2×
MoE 稀疏化N 改按「激活参数」记账，总参数解耦随激活比
合成数据模型造 D 喂下一代 → 可复利开放问题

同时，旧坐标轴在撞墙：全网过滤后的高质量英文 token 只有约 5~10T，预训练正逼近数据墙。于是 scaling 换了坐标轴接着画线——RL 后训练的样本量（早期证据：也是幂律，指数不同）、推理时算力（让模型多想几步再答）。规模化没有结束，只是换了自变量。

9 · 不训大模型的人，拿这些真理做什么

三个日常决策

① 微调数据够不够：任务数据远少于底模参数量的 20 token/参数时，预期损失会在某个地板上饱和——先补数据，别先怪超参。

② 选底模看账本：预算大头在推理，就选小而长训（高 D/N）的模型，而不是「同损失里最大的」——Llama 3 8B 式的选项就是为你造的（§5）。

③ 知道收益递减在哪：为最后 0.01 的损失付 10 倍价钱之前，先确认你的产品指标是连续改善的（§7），否则这笔算力买不到体感。

整套定律自己动手验证只要几行（与 code/main.py 同一组常数）：

A, B, alpha, beta, E = 406.4, 410.7, 0.34, 0.28, 1.69
def loss(N, D): return E + A/N**alpha + B/D**beta
def best(C):                      # 固定 C=6ND，在 log N 网格上找谷底
    grid = (10**(6 + i*0.01) for i in range(700))
    return min(((N, C/(6*N), loss(N, C/(6*N))) for N in grid), key=lambda t: t[2])
for C in (1e20, 1e22, 1e24):
    N, D, L = best(C)
    print(f"C={C:.0e}  N*={N:.2e}  D*={D:.2e}  D/N={D/N:.0f}  L={L:.3f}")

自检：跑出的三行应当与 §4 的表格一致；把 GPT-3 的 (175e9, 300e9) 代入 loss() 应得 ≈2.002，把 Chinchilla 的 (70e9, 1.4e12) 代入应得 ≈1.937——同一档算力，分账不同，命运不同。
