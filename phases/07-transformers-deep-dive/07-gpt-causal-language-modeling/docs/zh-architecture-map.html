GPT 架构全景图：参数与激活双色标注

decoder-only　尺寸沿用玩具（n = 3，d = 4，V = 10，单头）　深色块 = 参数　白色块 = 激活

一张图放大到矩阵级：深色块是训练学来的参数（躺在权重文件里，对所有输入相同——E、每层的 W_Q/W_K/W_V/W_O 与 FFN 升降维、末端的 U），白色块是运行时现算的激活（随输入变、用完即弃——X、Q/K/V、打分表、logits、概率）。右侧竖排是形状审计轨：任何一步形状接不上，就是理解或代码出了错的地方。

对照文字版：修订后的五步

1. prompt → 分词器 → n 个整数 id
2. 查嵌入表 E 取行拼成 X⁰（n×d，加位置信息）
3. 每个 transformer 块（= 注意力 + FFN 两个单元）：
     注意力：Q = X·W_Q，K = X·W_K，V = X·W_V（本层自己的 W）
             → 打分 ÷√d_k → 掩码 → softmax → 加权平均 → W_O → 残差加回
     FFN  ：每行独立 升维 → 非线性 → 压回 → 残差加回
   输出形状不变，仍 n×d
4. 重复 L 层（每层一组参数，分工自己长出来）→ Y = X^L（n×d）
5. 取末行（1×d）→ ×U（d×V）→ V 个 logits → ÷T → softmax → V 个概率
   → T = 0 恒取最大；T > 0 按概率抽签 → 新词粘回队尾，回到第 3 步

这张图怎么用

盯住两件事。一是双色：全图深色块合计就是权重文件的全部内容（玩具 656 个数字、Llama-3-8B 的 8.03B），白色块在每次前向里生灭一轮——分不清"学来的还是算出来的"时，回来看颜色。二是右侧形状轨：n 个整数 → n×d →（×L 不变）→ 1×d → 1×V → 1 个词；理解或代码哪里断了，形状轨会先于直觉告诉你断在哪。

同系列：玩具 GPT 全流程走查（图 1 管线俯瞰 / 图 2 自回归与 KV cache）　·　注意力机制单独拆解（本图注意力单元的逐格放大）　·　softmax 与 temperature（本图最后三格的逐格放大）。经典的 2017 原论文 Figure 1 画的是编码器-解码器双塔——GPT 只是它的右半塔砍掉 cross-attention，初学先看本图再看那张，能少绕一段路。
