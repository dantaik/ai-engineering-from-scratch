GPT 架构全景图：形状代数版

通用符号标注（括号内为玩具取值）　深色块 = 参数　白色块 = 激活　每条乘法边标注 (a×b)·(b×c) → a×c

矩阵乘法只有一条形状规则：(a×b)·(b×c) = a×c——内侧维度必须相等，相乘后被"吃掉"。整个 GPT 就是这条规则的一次长途接力：每一步吃掉一个中间维度、换出一个新维度，直到把 n 个整数换成 V 个概率。本图把每一步的进出形状全部写在边上。

参数矩阵的形状只含 d、d_k、d_v、d_ff、V——没有一个含 n；n 只出现在激活里。这就是同一个模型既能吃 3 个 token 也能吃十万个的结构原因。

1 · 一行看完全程的形状链

n ─查表─▶ n×d ─┬─ ×W_Q/W_K/W_V ─▶ n×d_k        （d 被吃掉，进工作坐标系）
               │   Q·Kᵀ÷√d_k    ─▶ n×n          （d_k 被吃掉，配对完成）
               │   掩码+softmax  ─▶ n×n          （逐元素，形状不变）
               │   A·V           ─▶ n×d_v        （第二个 n 被吃掉，前文收拢）
               │   拼接h头 ×W_O  ─▶ n×d          （回到黑板宽度）
               │   ＋残差        ─▶ n×d
               │   ×W_up         ─▶ n×d_ff       （d 换成 d_ff，展开模式）
               │   非线性        ─▶ n×d_ff       （逐元素，形状不变）
               │   ×W_down ＋残差─▶ n×d          （d_ff 被吃掉，压回黑板）
               └── 重复 L 层 ──▶ n×d
    取末行 ─▶ 1×d ─ ×U ─▶ 1×V   （d 被吃掉，换来词表轴）
    ÷T → softmax → 抽样 ─▶ 1 个词 ─ 粘回队尾，n＋1，重来

2 · 只有三类算子在改变输出

算子形状效果实例它在干什么
乘参数矩阵换掉最后一维：n×a → n×bW_Q/W_K/W_V、W_O、W_up、W_down、U换坐标系 / 换角色——每行独立变换，行与行不交流
乘激活矩阵消掉一个 n：行与行混合Q·Kᵀ（配对打分）、A·V（加权平均）唯一让 token 交流的操作——注意力的本体就这两下
逐元素操作形状完全不变softmax、非线性、残差相加、归一化、÷√d_k、÷T调整数值分布，不动结构

这就是"矩阵大小如何变化、如何改变输出"的全部语法：参数乘法换维度（列变换），激活乘法混行（行变换），逐元素只调数值。全模型任何一步都逃不出这三类——读任何新架构的论文，先把每步归入这三类，形状就永远不会跟丢。

两条自查线索

① 深色参数块的形状全不含 n——所以模型天然接受任意长度（n 只是激活的行数，上限来自位置编码与显存）。② 被"吃掉"的维度就是该步用完的资源：d_k 用于配对、第二个 n 用于遍历前文、d_ff 用于展开模式、最后的 d 用 U 换成 V——每次乘法都是一笔"以维度换信息"的交易。

3 · 对照文字版：五步（带形状）

1. prompt → 分词器 → n 个整数
2. 查 E（V×d）取行拼 X⁰ ＋位置信息                       → n×d
3. 每块：注意力（Q/K/V=X·W，打分÷√d_k，掩码，softmax，
         A·V，拼头×W_O，＋残差）                          → n×d
   MLP ：×W_up → n×d_ff → 非线性 → ×W_down，＋残差        → n×d
4. 重复 L 层（每层一组参数）→ Y                            → n×d
5. 末行（1×d）× U（d×V）→ logits ÷T → softmax → 概率      → 1×V
   T=0 取最大 / T>0 抽签 → 词粘回队尾，n+1，回到第 3 步
