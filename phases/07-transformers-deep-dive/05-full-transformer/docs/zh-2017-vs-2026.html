同一副骨架，六次换件：2017 原版 Transformer vs 2026 生产级方案

LayerNorm→RMSNorm · ReLU→SwiGLU · 4×→2.6× · Sinusoidal→RoPE · MHA→GQA/MLA · bias→无

骨架自 2017 年一天没变：embedding → N × (attention + FFN + 残差 + norm) → 输出头，attention 公式还是那一行 softmax(QKᵀ/√d)V。变的是六个零件——两个为了同参数下更好的质量（SwiGLU、RoPE），一个为了训练稳定（配套的 pre-norm），三个为了推理经济学（GQA/MLA、RMSNorm、去 bias）。这份讲义把课程表格的六行逐行拆开：2017 怎么做、2026 怎么做、为什么换、谁在用。

换件 1 / 6归一化：LayerNorm → RMSNorm

2017 · LayerNorm 
μ = mean(x)         σ² = var(x)
y = γ ⊙ (x − μ)/√(σ² + ε) + β

四步：减均值、除标准差、γ 缩放、β 平移。两组可学参数（γ、β）。

2026 · RMSNorm 
RMS(x) = √(mean(x²) + ε)
y = γ ⊙ x / RMS(x)

两步：除 RMS、γ 缩放。不减均值，没有 β。一组参数。

为什么换 · 动机：省算力，稳定性不减

RMSNorm 砍掉的是"中心化"：少一次对整个隐向量的均值归约，少一组平移参数。课程原话——省计算，且经验上至少一样稳定（empirically at least as stable）。归一化在每层出现两次、每个 token 都要算，这笔小账乘以层数和序列长度就不小了。这是典型的"消融后发现没用就删"：均值那一项对训练质量的贡献测不出来，于是不再付它的钱。

表格外的隐藏换件：位置也挪了（post-norm → pre-norm）。2017 年的写法是 LN(x + sublayer(x))——归一化站在残差相加之后，梯度回传必须穿过它。堆到十几层以上就难训，需要精细的学习率 warmup 伺候。2019 年后大家改成 x + sublayer(LN(x))——归一化挪到子层之前，残差通道从头到尾是一条干净的直通线，梯度畅行无阻，深堆叠稳定。课程 05 的结论：pre-norm 是 2026 默认，Llama、Qwen、GPT-3+、Mistral 全部在用。

谁在用Llama 全系QwenMistralDeepSeek-V3ModernBERT（encoder 侧也换了）

换件 2 / 6FFN 激活：ReLU → SwiGLU

2017 · ReLU FFN（两个矩阵） 
FFN(x) = W₂ · max(0, W₁x + b₁) + b₂

W₁: d → 4d
W₂: 4d → d

升维、硬开关（负数归零）、降维。

2026 · SwiGLU（三个矩阵） 
FFN(x) = W₂ · ( SiLU(W₁x) ⊙ W₃x )

SiLU(z) = z · σ(z)
W₁, W₃: d → h    W₂: h → d

两条支路逐元素相乘（⊙），再降维。

为什么换 · 动机：同参数下质量更好

结构上的新东西是门控：W₃x 这条支路算"内容"，SiLU(W₁x) 这条支路算"每一维放行多少"，逐元素相乘等于一个由数据现场决定的软阀门。ReLU 是硬开关——过不过由这一维自己的符号决定；SwiGLU 是软阀门——开度由另一条学出来的支路控制，且处处可导。课程给的数字：在 Llama、PaLM、Qwen 的论文里，SwiGLU 稳定优于 ReLU/GELU 约 0.5 困惑度。

花絮：提出 GLU 变体的 Shazeer 论文（2020）结尾原话——"We offer no explanation as to why these architectures seem to work; we attribute their success, as all else, to divine benevolence."（我们无法解释它为什么有效，只能归功于神恩。）先在实验上赢，再等理论解释——这行字是现代 LLM 架构工程的真实写照。

换件 3 / 6FFN 宽度：4× → 2.6×

这一行最容易被误读成"独立的设计决策"。它不是——它是换件 2 的记账后果。

2017 双矩阵参数：  2 · d · (4d)  =  8d²
SwiGLU 三矩阵参数： 3 · d · h

令两者相等（换激活不涨参数）：
3dh = 8d²   →   h = 8d/3 ≈ 2.67d
为什么是 2.6 · 动机：参数守恒

SwiGLU 比双矩阵结构多一个 W₃。如果中间层仍留 4×d，FFN 参数就凭空涨一半——和 ReLU 版就不再是公平对比，论文里的 0.5 ppl 优势也无从谈起。解方程得 h ≈ 2.67d，工程上取到硬件友好的整数：Llama 2 7B 的 d=4096，FFN 中间层 11008 = 2.69×d。所以表格里那句括号注释"total params match"才是这一行的全部内容：2.6 不是选出来的，是解出来的。

顺手算一层 block 的参数账（课程 05 的公式）：attention 四个投影 4d²，SwiGLU FFN 3·(2.6)·d² ≈ 7.9d²。d=4096 时每层约 2 亿参数，32 层约 63 亿，加上两头的嵌入矩阵——正好对上 Llama 3 8B 量级的公开数字。你能用两行乘法核出一个 7B 模型，靠的就是骨架没变。

换件 4 / 6位置信息：Sinusoidal 绝对位置 → RoPE

2017 · 入口加法

在 embedding 上加一个 sin/cos 位置向量，只在入口做一次，之后随残差流漂过所有层。

编码的是绝对位置：位置 5 有位置 5 的固定向量。超出训练长度即失效——外推差。

2026 · 每层现场旋转

embedding 不动。在每一层 attention 内部，把 Q 和 K 按位置角度成对旋转（V 不转）：

(q₂ᵢ, q₂ᵢ₊₁) 旋转角 θᵢ·m
θᵢ = base⁻²ⁱ/ᵈ，m 为绝对位置
为什么换 · 动机：相对位置 + 长上下文的免费旋钮

RoPE 的妙处在一条数学性质：旋转后 q'ₘ · k'ₙ 的值只依赖相对距离 (m − n)——用绝对位置执行的操作，在点积里编码出了相对位置（课程 07·04 的验证练习：把两个位置同时平移 k，点积分毫不变）。注意力天然更关心"隔多远"而不是"在第几格"，这正中要害。

第二个红利是那个 base 超参：推理时缩放它（NTK-aware / YaRN / LongRoPE）就能不重训地外推上下文——Llama 3 从 8K 扩到 128K 就是这么做的。sinusoidal 没有这样的旋钮。另一条支线 ALiBi 干脆不用嵌入，直接在注意力分数上按距离加线性惩罚，外推极好，但 2026 年的主流答案是 RoPE。

换件 5 / 6注意力：Full MHA → GQA（或 MLA）

前四个换件都发生在训练图纸上；这一个是被推理账单逼出来的。生成时每个已处理 token 的 K、V 都要缓存（KV cache），否则每步重算整个前缀。缓存大小：

每 token 每层字节数 = 2 (K和V) × KV头数 × d_head × 精度字节数

课程 07·12 的账：7B 模型（32 层 × 32 头 × d_head 128，fp16）每 token 16 KB，32K 上下文吃掉 512 MB；如果 70B 级别 80 层全 MHA，32K 上下文的缓存就是 32 GB——光缓存就挤满一张 40 GB A100。质量不逼你换，显存逼你换：

方案KV 头数缓存缩减质量代表
MHA（2017）= Q 头数1×（基准）最好原版 · GPT-2 · BERT
MQA（2019）1÷ 头数（12–32×）难题略掉分早期 PaLM
GQA（2023）分组共享÷ 组倍数≈ MHALlama 3 · Qwen · Mistral
MLA（2024）共享低秩 latent比 MQA 还小≈ MHADeepSeek-V2/V3 · Kimi K2
两条现役路线 · 动机：砍推理显存，不砍质量

GQA（分组查询注意力）：Q 头保持全额，K/V 头按组共享。Llama 3 8B 是 32 个 Q 头共享 8 组 KV——缓存直接 ÷4；70B 同样 8 组 KV，32K 上下文从 32 GB 降到 10.4 GB。质量与 MHA 几乎无差。

MLA（多头潜在注意力）：更激进——K、V 先压进一个共享的低秩 latent 向量（DeepSeek-V3 每 token 每层只缓存约 512 个数，GQA-8 要 1024 个），用时再逐头升维解压，且升维矩阵可以吸收进后续矩阵乘，不付额外代价。每个头保住了自己独立的表达，缓存却比 MQA 还小。

课程 10·14 的判语：13B 以上的模型，GQA 或 MLA 实际上是强制项——全 MHA 在规模上就是一场 KV cache 灾难。

换件 6 / 6Bias 项：有 → 无

2017 
y = Wx + b

每个线性层都带偏置项，LayerNorm 还有平移参数 β。

2026 
y = Wx

attention 四个投影、FFN 三个矩阵，全部裸乘。RMSNorm 本身就没有 β。

为什么删 · 动机：测不出贡献的参数不留

课程 05 关键词表对 bias-free 的注解：困惑度还略有改善，模型更小。直觉：每层都有归一化重新居中缩放整个数据流，紧邻的 bias 能表达的平移量，norm 的参数和下一层权重几乎都能吸收——它在大规模下测不出独立贡献。删掉后参数省一点、显存省一点、kernel 简单一点。和 RMSNorm 砍均值、NSP 被 RoBERTa 砍掉是同一种精神：2026 年的默认审美是消融驱动的极简——凡是消融后测不出差别的，一律不留。

尾声什么没变，以及去哪里深挖

六次换件之后，清点一下没动过的东西：token embedding 进、N 层 block 堆叠、每层"注意力混合位置 + FFN 逐位变换 + 残差直通 + 归一化稳流"、因果掩码、next-token 交叉熵损失，以及 attention 公式本身——softmax(QKᵀ/√d)V 一个符号没改。骨架是 2017 年的，零件是这九年里一件件换上的：

一句话收束

把六行按动机归类只有三类：为了训练得更稳（pre-norm 换位）、为了同样的参数买到更好的质量（SwiGLU、RoPE）、为了推理时少花钱（GQA/MLA 砍显存，RMSNorm、去 bias 省小钱）。没有一项是为了改变模型"是什么"——它们都在优化同一副骨架"跑多快、堆多深、服务多便宜"。这也是读任何 2026 新模型技术报告的正确姿势：先默认六件套齐装（RMSNorm + pre-norm + SwiGLU + RoPE + GQA/MLA + 无 bias），再找它与默认的差分。
